# Changelog

## 1.1.0

- Replace the Jikan transport with direct MyAnimeList API v2 requests.
- Keep MyAnimeList manga IDs as stable source IDs.
- Require the host application to provide its own MyAnimeList client identifier.

## 1.0.0

- Add a read-only manga catalog backed by live MyAnimeList-derived metadata through Jikan v4.
- Use MyAnimeList manga IDs as stable source IDs.
- Provide top manga, title search, details, cover, score, authors, aliases, genres, and popularity rank.
